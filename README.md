# LSFusion project: Система тестирования студентов

Реализован учебный проект на `lsFusion` для тестирования студентов:

- ввод справочников студентов и дисциплин;
- ввод тестов, вопросов и вариантов ответа;
- запуск прохождения теста студентом;
- фиксация ответов и пересчет результата;
- отчетность по попыткам / студентам / дисциплинам;
- условное форматирование результатов в отчетах;
- экспорт/импорт сессий в `JSON`, экспорт в `XLS`.

## Где находится логика

- `docker-server/src/main/lsfusion/catalog/Student.lsf` — студенты;
- `docker-server/src/main/lsfusion/catalog/Discipline.lsf` — дисциплины;
- `docker-server/src/main/lsfusion/testing/Question.lsf` — тесты, вопросы, варианты;
- `docker-server/src/main/lsfusion/testing/TestingSession.lsf` — прохождение теста;
- `docker-server/src/main/lsfusion/reports/PerformanceReport.lsf` — аналитические отчеты.

## Что покрыто по требованиям

- формы списков и формы редактирования объектов;
- ограничения (`CONSTRAINT`) на корректность и уникальность данных;
- события (`WHEN SET`) для автозаполнения и значений по умолчанию;
- условное форматирование ячеек в отчетах (цвет в зависимости от результата);
- импорт/экспорт данных (`IMPORT/EXPORT`) в JSON/XLS.
